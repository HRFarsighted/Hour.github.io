# Rui Hou — Academic Homepage

Static personal academic website for GitHub Pages.

## Local preview

Open `index.html` directly, or serve the folder with any static HTTP server.

## Updating content

- Main content: `index.html`
- Visual system and responsive layout: `styles.css`
- English/Chinese language switch: `script.js`

GitHub Pages publishes the root of the `main` branch at `https://hrfarsighted.github.io/`.
